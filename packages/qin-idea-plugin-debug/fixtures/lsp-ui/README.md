# Qin IDEA LSP UI Fixture

Open this directory with the IDEA plugin to verify that `.qin`, `.ovs`, and
`.cssts` files are handled by the LSP integration.

Expected behavior:

- `good.qin`, `good.ovs`, and `good.cssts` open without syntax diagnostics.
- `bad.qin`, `bad.ovs`, and `bad.cssts` show language-server diagnostics.
